Open Aqua 0.5.0 source tree
Updated: 2026-08-25

Included:
- React Native / Expo application source
- Owner authentication and password recovery
- Encrypted session storage
- Local-first, account-scoped tank storage
- Supabase migration and owner-only Row Level Security
- Cloud sync, realtime refresh, retry and conflict merge
- Open Aqua OS constitution, module registry and capability governance
- Asia-first freshwater product modules and hard product boundaries
- Expanded manual parameters and specific care-action capture
- Cloud-compatible livestock, plant, equipment, photo and care-task contracts
- Tank-context packet for future tank-aware guidance
- Privacy-safe blank owner state and Singapore-first tank onboarding
- Native Sign in with Apple plus independent email authentication
- Conservative migration that never overwrites an owner-modified tank
- Structured concern facts, bounded test estimates and deterministic safety priority
- Tiered nitrite, progressive-wasting, serial-loss and breathing-emergency rules
- Concern outcome history with conflict-safe two-device merging
- Governed capabilities across 13 operating-system modules
- Data export and server-side account deletion function
- EAS/TestFlight configuration
- Privacy, security, setup and App Store release documents
- Automated tests and GitHub Actions workflow

Intentionally excluded:
- node_modules, dist and .expo generated directories
- .env and all live credentials
- Apple certificates and provisioning profiles
- Supabase service-role keys
- Expo or GitHub authentication tokens

Verification source:
- `npm run verify` for TypeScript and automated tests
- `npm run release:check` for verification plus the iOS bundle export
- `.github/workflows/quality.yml` for repository CI evidence
- `src/os/capabilities.ts` for current delivery states

Account-bound activation still required:
- Create and configure the owner's Supabase project
- Create and configure the owner's Expo/EAS project
- Create the owner's Apple Developer and App Store Connect records
- Build with EAS, test on a real iPhone, and submit through TestFlight

See SETUP_SIMPLE.md and APP_STORE_RELEASE.md.
